# invalid — DDNet-клиент с эвристическим анализом игроков

Форк [DDNet](https://github.com/ddnet/ddnet) с отдельным меню настроек **invalid**.

## Что уже есть (этап 1)

- Вкладка **invalid** в «Настройках» (последняя, после «Credits»).
- Всё на русском языке.
- Компонент `CInvalid`, зарегистрированный как обычный клиентский компонент DDNet.
- Оверлей справа сверху: статус игрока по трём градациям — **легит / мутный / софт**.
  Пока показывает «нет данных»: честный заглушка до этапа 3, а не выдуманный процент.
- Список игроков с кнопками **Спек** (авто-спек за выбранным) и **Анализ**.
- Питомцы: сфера / звезда / радуга, летают за локальным ти.
- Ушки: 5 вариантов.
- Локальный пранк: дождевое облачко над головой. **Другие игроки его не видят**,
  непристойной графики нет.
- Консольные команды для биндов:

  | Команда | Действие |
  | --- | --- |
  | `invalid_menu` | Открыть меню invalid |
  | `invalid_prank` | Локальный пранк |
  | `invalid_analyze` | Предварительный анализ игроков |
  | `invalid_spectate <id>` | Спектатор за игроком |
  | `invalid_pet <0..3>` | Питомец |
  | `invalid_ears <0..5>` | Ушки |

## Важное про анализ

Оценка «на сколько процентов игрок читер» — **эвристика**, а не доказательство.
Любая система такого рода даёт ложные срабатывания. Результаты предназначены для
личного просмотра и должны проверяться вручную по демо. Не публикуйте их как
обвинение в адрес других игроков.

## Планы

Подробный разбивка по этапам: [docs/PLAN.md](docs/PLAN.md).

- Этап 2 — загрузка картинки/скина питомца, расширение набора ушек, доработка UI.
- Этап 3 — парсинг `.demo`, эвристики аима/авоида/аима по молоту/автоанфриза,
  процент и текстовые причины в оверлее.
- Этап 4 — фон меню с дождём и молниями, финальная полировка, релиз.

## Сборка

Репозиторий — форк DDNet, поэтому собирается так же, как DDNet.
Готовые сборки Windows и Linux собираются в GitHub Actions (см. `_release.yml`).

Локально (нужны git, CMake, компилятор и зависимости DDNet):

```sh
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target DDNet
```
