# invalid — DDNet-клиент с эвристическим анализом игроков

Форк [DDNet](https://github.com/ddnet/ddnet) с отдельным меню настроек **invalid**.

## Что есть

- Вкладка **invalid** в «Настройках» (последняя), всё на русском.
- **Анализ демок**: укажи путь к `.demo` в меню (или `invalid_load_demo <путь>`) и нажми «Загрузить демо и проанализировать». Демо читается через штатный `CDemoPlayer`, snapshots разбираются по сети, по каждому игроку считаются:
  - резкие доводки прицела (aim);
  - уклонение от снарядов (avoid);
  - аим по молоту;
  - автоанфриз (стабильно короткие заморозки).
  Итог — процент 0..100, вердикт **легит / мутный / софт** и текстовые причины в оверлее справа сверху.
- **Спектатор**: кнопка «Спек» за каждым игроком (`invalid_spectate <id>`).
- **Питомцы**: сфера, звезда, радуга; можно задать свою `.png` картинку полным путём.
- **Ушки**: 6 вариантов (выкл + 5).
- **Фон меню**: анимированный дождь и молнии (в меню или всегда).
- **Локальный пранк**: дождевое облачко над головой. Другие игроки его не видят, непристойной графики нет.
- Кнопки в стиле DDNet с цветовыми состояниями.

## Команды

| Команда | Действие |
| --- | --- |
| `invalid_menu` | Открыть меню invalid |
| `invalid_prank` | Локальный пранк |
| `invalid_load_demo <путь>` | Загрузить `.demo` и запустить анализ |
| `invalid_analyze` | Список игроков текущего сервера |
| `invalid_spectate <id>` | Спектатор за игроком |
| `invalid_pet <0..3>` | Питомец |
| `invalid_ears <0..5>` | Ушки |

## Важное про анализ

Процент — **эвристика, а не доказательство**. Система может ошибаться и давать ложные срабатывания.
Результаты предназначены для личного просмотра; всегда проверяй демо вручную и не публикуй оценку
как обвинение.

## Сборка

Готовые сборки Windows и Linux: [Releases](https://github.com/kostadaun333-del/ddnet-invalid-client/releases).

Локально (нужны git, CMake, компилятор и зависимости DDNet):

```sh
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target game-client
```
