# invalid — DDNet-клиент с эвристическим анализом игроков

Форк [DDNet](https://github.com/ddnet/ddnet) с отдельным меню настроек **invalid**.

## Что есть

- Вкладка **invalid** в «Настройках» (последняя), всё на русском.
- **Анализ демок**: укажи путь к `.demo` в меню (или `invalid_load_demo <путь>`) и нажми «Загрузить демо и проанализировать». Демо читается через штатный `CDemoPlayer`, snapshots разбираются по сети, по каждому игроку считаются:
  - резкие доводки прицела (aim);
  - уклонение от снарядов (avoid);
  - аим по молоту;
  - автоанфриз (стабильно короткие заморозки).
  Итог — процент 0..100, вердикт **легит / мутный / софт** и текстовые причины в оверлее справа сверху.
- **Спектатор**: кнопка «Спек» за каждым игроком (`invalid_spectate <id>`).
- **Питомцы**: сфера, звезда, радуга; можно задать свою `.png` картинку полным путём.
- **Ушки**: 6 вариантов (выкл + 5).
- **Фон меню**: анимированный дождь и молнии (в меню или всегда).
- **Локальный пранк**: дождевое облачко над головой. Другие игроки его не видят, непристойной графики нет.
- Кнопки в стиле DDNet с цветовыми состояниями.
- **Подпись клиента**: серверу и модераторам передаётся `invalid client 1337` вместо `DDNet <версия> (<git hash>)`.
- **AI-помощник** (вкладка **AI** в «Настройках»):
  - текстовый запрос → ответ голосом; по умолчанию используется бесплатный OpenAI-совместимый API Pollinations **без ключа**;
  - **триггер в чате**: по умолчанию ИИ отвечает, когда ты пишешь сообщение со словом «ии» (можно поменять слово и режим: только кнопки / триггер / любое сообщение); текст после триггера считается вопросом;
  - **голосовой ввод**: команда `ai_listen` (или кнопка в меню) слушает микрофон — говоришь, ИИ отвечает голосом. Можно забиндить: `bind k ai_listen`. На Windows используется системный распознаватель через PowerShell, на Linux — `arecord` + `whisper`;
  - запросы ставятся в очередь и отправляются с интервалом **5 секунд** (меняется в меню), ничего не теряется;
  - кнопка «Роаст меня» — комедийная подшуточка над тобой и твоим ником, **только локально и только для тебя**; response не уходит в общий чат, если не включить отдельный пункт;
  - голос по умолчанию локальный: Windows SAPI, Linux `espeak-ng` / `espeak` / `spd-say` (ключ и интернет для озвучки не нужны); в меню можно выбрать имя конкретного установленного голоса (например `Yulia` или `Zira`);
  - для красивого голоса включи **«Использовать API-TTS»**: по умолчанию уже выставлены OpenAI `gpt-4o-mini-tts` и голос `nova`, достаточно вписать свой API-ключ; звук идёт opus через штатный декодер DDNet;
  - во время озвучки сверху появляется HUD **«AI ГОВОРИТ»** с анимированным эквалайзером и текстом ответа.

## Команды

| Команда | Действие |
| --- | --- |
| `invalid_menu` | Открыть меню invalid |
| `invalid_prank` | Локальный пранк |
| `invalid_load_demo <путь>` | Загрузить `.demo` и запустить анализ |
| `invalid_analyze` | Список игроков текущего сервера |
| `invalid_spectate <id>` | Спектатор за игроком |
| `invalid_pet <0..3>` | Питомец |
| `invalid_ears <0..5>` | Ушки |
| `ai_menu` | Открыть настройки AI |
| `ai_ask <текст>` | Спросить AI, ответ голосом |
| `ai_roast` | Локальный роаст (только для тебя) |
| `ai_say <текст>` | Озвучить текст локальным голосом |
| `ai_listen` | Слушать микрофон и спросить AI голосом |

## Про AI

Бесплатный публичный endpoint имеет лимит (примерно один запрос в 30–45 секунд на IP) и может временно отвечать `HTTP 402` — это нормально, просто повтори позже или вставь свой ключ/эндпоинт в настройках. Локальный голос работает без ключа: на Windows используется встроенный SAPI, на Linux нужно поставить `espeak-ng` (`sudo apt install espeak-ng`). Ответы по умолчанию остаются только у тебя; отправка в общий чат включается отдельной галочкой.

## Важное про анализ

Процент — **эвристика, а не доказательство**. Система может ошибаться и давать ложные срабатывания.
Результаты предназначены для личного просмотра; всегда проверяй демо вручную и не публикуй оценку
как обвинение.
